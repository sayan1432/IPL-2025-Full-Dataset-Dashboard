# 🏏 IPL 2025 Full Dataset Dashboard

A fully interactive Streamlit dashboard visualizing IPL 2025 data — including Orange Cap, Purple Cap, Points Table, Auction stats, and Match Schedule.

🔗 **Live App**: [Click to View](https://sayan-ipl-2025-full-dataset-dashboard-qxy3j8a4wqemzjxmxkheea.streamlit.app)

---

## 🚀 Features

- 🟠 Orange Cap leaderboard
- 🟣 Purple Cap leaderboard
- 📊 Points table visualization
- 📅 Match schedule with filters
- 💰 Auction insights
